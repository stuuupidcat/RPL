## 谓词含义

| 谓词                                                  | 含义                                     |
| ----------------------------------------------------- | ---------------------------------------- |
| `is_null(location, value)`                          | 指针为空                                 |
| `eq_const(location, value, const)`                  | 值等于常量                               |
| `ne_const(location, value, const)`                  | 标量的可能值不含常量；序列每个元素的可能值均不含常量 |
| `lt_const(location, value, const)`                  | 值小于常量                               |
| `le_const(location, value, const)`                  | 值小于等于常量                           |
| `gt_const(location, value, const)`                  | 值大于常量                               |
| `ge_const(location, value, const)`                  | 值大于等于常量                           |
| `not_power_of_two(location, value)`                 | 值不是 2 的幂                            |
| `rounded_up_gt_const(location, value, step, const)` | `value` 按 `step` 向上取整后超过常量 |
| `byte_slice_is_empty(location, value)`              | 字节切片为空                             |
| `byte_slice_last_byte_not_nul(location, value)`     | 非空字节切片的最后一个字节不是 NUL       |
| `contains_interior_nul(location, value)`            | 字节切片在结尾前包含 NUL                 |
| `value_invalid_for_type(location, value, type)`     | `value` 是 `type` 不允许的值，例如 `bool` 为 2 |
| `add_gt_const(location, left, right, const)`        | `left + right > const` |
| `add_lt_const(location, left, right, const)`        | `left + right < const` |
| `sub_lt_const(location, left, right, const)`        | `left - right < const` |
| `sub_gt_const(location, left, right, const)`        | `left - right > const` |
| `mul_lt_const(location, left, right, const)`        | `left * right < const` |
| `mul_gt_const(location, left, right, const)`        | `left * right > const` |
| `size_mul_lt_const(location, value, type, const)`   | `value * size_of::<type>() < const` |
| `size_mul_gt_const(location, value, type, const)`   | `value * size_of::<type>() > const` |
| `slice_size_gt_const(location, slice, const)`       | `len(slice) * size_of::<element>() > const` |
| `index_ge_len(location, collection, index)`         | `index >= len(collection)`             |
| `index_gt_len(location, collection, index)`         | `index > len(collection)`              |
| `range_start_gt_end(location, range)`               | `range.start > range.end`              |
| `range_start_gt_len(location, collection, range)`   | `range.start > len(collection)`        |
| `range_end_gt_len(location, collection, range)`     | `range.end > len(collection)`          |
| `range_end_ge_len(location, collection, range)`     | `range.end >= len(collection)`         |
| `layout_size_eq_const(location, layout, const)`      | `layout.size() == const`               |
| `layout_size_gt(location, left, right)`              | `left.size() > right.size()`           |
